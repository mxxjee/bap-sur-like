# 밥서라이크

> 먹고, 커지고, 살아남아라!

음식 몬스터를 쓰러뜨리고 경험치 음식 조각을 직접 먹으며 성장하는 모바일 세로형 웹 생존 게임입니다.

## 바로 플레이하기

[GitHub Pages에서 밥서라이크 실행](https://mxxjee.github.io/bap-sur-like/)

> GitHub Pages 공개 설정이 아직 완료되지 않았다면 링크가 일시적으로 열리지 않을 수 있습니다.

## 게임 규칙

- 자동 공격으로 몰려오는 음식 몬스터를 처치합니다.
- 처치된 몬스터가 떨어뜨린 경험치 음식 조각을 직접 먹어야 경험치와 몸집이 증가합니다.
- 몸집이 커질수록 이동 속도가 느려집니다.
- 레벨업하면 게임 월드가 멈추고 세 가지 강화 중 하나를 선택할 수 있습니다.
- 강화를 선택하면 몸집과 몸집으로 인한 임시 감속은 초기화되고, 영구 강화 효과는 유지됩니다.
- 제한 시간 동안 살아남으면 승리합니다.

## 조작 방법

### PC

- 이동: `WASD` 또는 방향키
- 공격: 가장 가까운 적을 향해 자동 공격
- 일시 정지: 화면 상단의 일시 정지 버튼

### 모바일

- 이동: 게임 화면 중앙 하단의 가상 조이스틱을 드래그
- 공격: 가장 가까운 적을 향해 자동 공격
- 세로 화면 플레이 권장

## 주요 기능

- 적 생성량과 종류가 시간에 따라 달라지는 웨이브형 생존 전투
- 경험치 진행도와 분리된 몸집 성장 및 이동 속도 변화
- 레벨업 시 무작위 3개 강화 선택과 영구 강화 누적
- 투사체, 피격, 처치, 경험치 획득, 레벨업 시각 효과
- Web Audio API 기반 효과음
- PC와 모바일을 지원하는 반응형 세로 게임 화면
- Supabase 기반 평가 등록, 최근 평가 조회, 평균 별점과 전체 평가 수 표시
- Supabase 미연결 시 안내 및 `localStorage` 임시 저장
- 별도 빌드 없이 GitHub Pages에서 실행 가능한 정적 웹 구조

## 사용 기술

| 구분 | 기술 |
| --- | --- |
| 게임 | HTML5 Canvas, Vanilla JavaScript |
| UI | HTML5, CSS3 |
| 사운드 | Web Audio API |
| 평가 데이터 | Supabase JavaScript Client, PostgreSQL, RLS |
| 배포 | GitHub Pages |

## 현재 개발 상태

- 최초 플레이 가능한 프로토타입 구현 완료
- 경험치와 몸집 진행도 분리 및 레벨업 후 몸집 초기화 적용
- 반응형 UI와 모바일 조작 개선 적용
- Supabase 평가 등록·조회 연동 및 공개용 클라이언트 설정 적용
- `feature/polish-pass` 브랜치에서 공개 배포 후보 버전 검증 중
